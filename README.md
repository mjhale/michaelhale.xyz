# Michael Hale's Website

A website for Michael Hale that showcases featured projects, technical skills, and more.

## Stack

- Next.js App Router
- React 19
- Tailwind CSS
- MDX and YAML content compiled into the application by Turbopack
- Dockerized production runtime

## Setup

```bash
git clone git@github.com:mjhale/michaelhale.com.git
cd michaelhale.com
corepack enable
pnpm install
pnpm dev
```

App runs at [http://localhost:3000](http://localhost:3000).

## Scripts

- `pnpm dev`: Sync assets, start local Next dev server with Turbopack
- `pnpm build`: Sync assets, build production app with Turbopack
- `pnpm start`: Serve an existing production build
- `pnpm test:e2e`: Run the Playwright instant-navigation and responsive-image suite
- `pnpm lint`: Run ESLint

## Content model

- Work entries: `content/work/**/**/*.mdx`
- Technology records: `content/technologies/*.yml`
- Turbopack eagerly compiles the content and generated image manifest into the server bundles
- Public assets are generated by `scripts/sync-assets.mjs` into `/public` before development and production builds

Development watches imported MDX and YAML files for changes. Production content and
public assets are build artifacts, so content changes require a new application build
and container image.

## Deployment

The application is containerized using Podman and supports multi-platform builds. The
build stage runs on `$BUILDPLATFORM`, while production dependencies are installed on
`$TARGETPLATFORM` so native Next.js dependencies match the runtime architecture. The
runtime image includes the complete `.next` build, target-platform production
dependencies, and generated public assets; source content is already compiled and is
not copied into the image.

For normal builds, avoid `--no-cache` so Podman can reuse build layers. Pre-generating
assets before a multi-platform build keeps the expensive image sync work warm:

```bash
# Pre-generate public assets
pnpm prebuild

# Build for multiple platforms
podman build --platform linux/amd64,linux/arm64 \
  --manifest ghcr.io/mjhale/michaelhale.com:latest .

# Push latest
podman manifest push --all \
  ghcr.io/mjhale/michaelhale.com:latest \
  docker://ghcr.io/mjhale/michaelhale.com:latest

# Push git commit tag
podman manifest push --all \
  ghcr.io/mjhale/michaelhale.com:latest \
  docker://ghcr.io/mjhale/michaelhale.com:$(git rev-parse HEAD)

# Run container
podman run -d -p 3000:3000 --env-file .env \
  --name michaelhale.com ghcr.io/mjhale/michaelhale.com:latest
```

Asset sync uses `SYNC_ASSETS_CONCURRENCY=4` by default. Tune that value for your
machine if image generation competes too heavily with other work.
